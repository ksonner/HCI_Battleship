# HCI_Battleship
---
### Teammates: Kathryn, Alex, Daniel
---
For this program we created an accessable Battleship. For this game, the player can either use their mouse, the arrow keys or voice recognition to place their ships and then chose spaces to bomb. 
---
This project is written in python utilizing the ______ libraries.
---
Controls:
<br>
Click on a ship to select it.
<br>
Click on the selected ship to deselect it.
<br>
Click on an empty space to move the selected ship there.
<br>
Press R to rotate the selected ship.
<br>
If the ship cannot be rotated or moved to the chosen cell it will not change and will stay selected.
